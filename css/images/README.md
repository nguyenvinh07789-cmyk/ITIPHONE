## 1. Giới thiệu Đồ án
Website được xây dựng dựa trên giao diện tĩnh (HTML5 & CSS3) tích hợp hai chủ đề công nghệ thực tế:
*   **Sale iPhone:** Hệ thống hiển thị, báo giá và cung cấp thông tin trải nghiệm các dòng sản phẩm Apple iPhone mới nhất.
*   **Việc làm IT (IT Jobs):** Không gian tuyển dụng nhân sự ngành công nghệ thông tin, kết nối các lập trình viên với doanh nghiệp.

## 2. Yêu cầu Kỹ thuật Đạt được
*   **Số lượng trang:** Đảm bảo tối thiểu 04 trang HTML cấu trúc nội dung phù hợp từng chủ đề.
*   **Bố cục giao diện:** Thiết kế đồng nhất hệ thống màu sắc thanh lịch, thanh điều hướng cố định (Sticky Navigation) và chân trang rõ ràng.
*   **Tính tương thích (Responsive):** Giao diện tự động co giãn tối ưu hiển thị tốt trên cả màn hình máy tính (Desktop) và điện thoại di động (Mobile) bằng Grid Layout & Flexbox.
*   **Mã nguồn sạch:** Tổ chức cây thư mục chuẩn hóa, các liên kết nội bộ hoạt động chính xác, mã nguồn không có lỗi hiển thị.

## 3. Cấu trúc Thư mục Dự án
Dự án được tổ chức sắp xếp logic theo đúng mô hình hướng dẫn:
```text
project/
├── index.html        # Trang chủ giới thiệu tổng quan hệ thống
├── about.html        # Trang giới thiệu thông tin doanh nghiệp
├── products.html     # Trang hiển thị danh sách iPhone & Việc làm IT
├── contact.html      # Trang form đăng ký tư vấn hoặc ứng tuyển việc làm
├── css/
│   └── style.css     # File định dạng CSS responsive dùng chung toàn bài
├── images/           # Thư mục chứa các tài nguyên hình ảnh minh họa bài viết
└── README.md         # File tài liệu hướng dẫn kỹ thuật này
```

## 4. Hướng dẫn Triển khai & Xem trực tiếp
1. Toàn bộ mã nguồn đã được tải lên kho lưu trữ **GitHub**.
2. Website được xuất bản trực tuyến công khai thông qua **GitHub Pages**.
3. Đường dẫn truy cập trực tiếp website dự án được lưu trong file `url.txt` gửi kèm trong tệp nộp bài `.zip`.
